# gomd — 原生 Win32 Markdown 浏览器

这是一个用 **纯 Go + Win32 API** 实现的 Markdown 阅读器，不依赖 WebView、Electron 或任何第三方 GUI 框架。渲染基于 [goldmark](https://github.com/yuin/goldmark) 解析、GDI 自绘。

## 功能特性

- 原生窗口 / 工具栏 / 菜单 / 状态栏 / 文件列表
- GFM 支持：表格、任务列表、删除线
- 实时缩放（Ctrl + 滚轮）
- 链接点击跳转（自动用默认浏览器打开）

## 文本样式

支持 **粗体**、*斜体*、~~删除线~~，以及 `行内代码`。

> 引用块也是支持的，可以用来强调重要内容。

## 代码块

```go
package main

import "fmt"

func main() {
	fmt.Println("Hello, gomd!")
}
```

## 有序与无序列表

1. 打开文件或文件夹
2. 在左侧列表选择 Markdown
3. 右侧即时预览

- 支持中文与英文混排
- CJK 逐字断行，西文按词断行

## 表格

| 快捷键 | 功能 |
| --- | --- |
| Ctrl+O | 打开文件 |
| Ctrl+F | 打开文件夹 |
| Ctrl+L | 显示/隐藏列表 |
| F5 | 重新加载 |

列对齐（左 / 居中 / 右）与多行单元格：

| 项目 | 状态 | 数量 |
| --- | :---: | ---: |
| 苹果 | 充足 | 128 |
| 香蕉 | 偏少 | 7 |
| 这是一个很长的单元格，用来验证超宽内容是否会自动折行、行高是否正确撑开、以及边框是否仍然对齐 | 充足 | 1024 |
